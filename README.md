# AI-Weather-Risk-Analysis

โปรเจครายวิชาการคิดเชิงออกแบบสำหรับวิทยาการข้อมูล เรื่อง **ระบบวิเคราะห์ความเสี่ยงจากสภาพอากาศด้วย AI ขนาดเล็ก**

## 🌦️ ระบบวิเคราะห์ความเสี่ยงสภาพอากาศ (AI Weather Risk Analysis System)

เป็นระบบเว็บแอปพลิเคชันที่ช่วยวิเคราะห์ความเสี่ยงของสภาพอากาศในแต่ละจังหวัดของประเทศไทย โดยใช้ข้อมูลจาก API สภาพอากาศและโมเดล AI ขนาดเล็กในการประเมินความเสี่ยง

ระบบถูกออกแบบมาเพื่อช่วยให้ผู้ใช้สามารถตรวจสอบสภาพอากาศแบบเรียลไทม์ และรับคำแนะนำเกี่ยวกับความเสี่ยง เช่น อากาศร้อนจัด ฝนตกหนัก หรือความชื้นสูง

---

## ⭐ ฟีเจอร์หลัก (Features)

* ฟีเจอร์ที่ 1 เลือกจังหวัดจาก **77 จังหวัดของประเทศไทย**
* ฟีเจอร์ที่ 2 ดึงข้อมูลสภาพอากาศแบบ Real-time จาก API
* ฟีเจอร์ที่ 3 แสดงข้อมูลอากาศ เช่น อุณหภูมิ ความชื้น และปริมาณฝน
* ฟีเจอร์ที่ 4 ระบบ **AI Risk Analyzer** วิเคราะห์ระดับความเสี่ยง
* ฟีเจอร์ที่ 5 แสดงคำแนะนำสำหรับผู้ใช้ตามระดับความเสี่ยง

## 🧠 แนวคิด AI ที่ใช้

ระบบใช้ **โมเดล AI ขนาดเล็ก (Lightweight AI Model)** ที่ประเมินความเสี่ยงจากข้อมูลหลัก ได้แก่

* อุณหภูมิ (Temperature)
* ความชื้น (Humidity)
* ปริมาณฝน (Rainfall)

โดยโมเดลจะคำนวณคะแนนความเสี่ยง และแสดงผลเป็น 3 ระดับ

* 🟢 ความเสี่ยงต่ำ
* 🟠 ความเสี่ยงปานกลาง
* 🔴 ความเสี่ยงสูง

พร้อมคำแนะนำในการปฏิบัติตัวตามสภาพอากาศ
